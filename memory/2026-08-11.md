## 주역 앱에 기문둔갑 추가 (3가지 점법)
- 지우 요청: 기문둔갑 추가, 총 3가지 선택 방식
- lunar.js 1.6.12에는 기문둔갑 미지원 (최신 1.7.7도 없음) → qimen.js 직접 구현
- qimen.js: 시가(時家) 기문둔갑 엔진
  - 24절기 상중하원 → 음둔/양둔 국수 (전통 국수 테이블)
  - 절기 당일 일진의 순수(旬首) 지지로 원 결정
  - 지반(6의3기) → 時干 → 직부궁 → 值符星/值使門
  - 천반(9성) · 인반(8문) · 신반(8신) 배치 (양둔 순행/음둔 역행, 8신 항상 순행)
  - 중궁(5)의 干은 2궁으로 붙는 전통 규칙 적용
  - 길흉: 門(開休生=길, 死驚傷=흉) + 星(輔心禽=길, 蓬芮=흉) + 神(값부·태음·육합·구지·구천=길) 점수제 → 대길~대흉 5단계
- index.html: 탭 3개 (생년월일시/기문둔갑/동전), 기문둔갑은 출생시각(생일 필드 연동) or 지금 시각 선택, 9궁 그리드 + 판정 + 시간궁 해석, 히스토리 연동
- 검증: 5개 시각 케이스 전통 규칙과 일치 (지우 생일 1968-10-19 12:00 → 寒露 중원 음둔9국, 직부궁 2궁, 死門+天芮 → 흉)
- 참고: 천반의 天禽 처리는 단순화 (MVP). 더 정밀한 버전 필요시 개선 가능
