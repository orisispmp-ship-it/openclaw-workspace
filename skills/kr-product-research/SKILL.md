# 제품 추천·가격 조사 (한국 쇼핑몰)

하드웨어 제품/액세서리 추천·가격 비교·호환성 확인 요청에 쓴다. 목표는 "확인한 사실"과 "추론"을 섞지 않고 제품 3개 내외를 근거와 함께 제시하는 것.

## 절차

1. 대상 기기의 규격을 제조사 공식 사양 페이지에서 먼저 확정한다. `apple.com/kr/<제품>/specs/` 같은 공식 페이지를 web_fetch하면 치수와 버튼·포트 위치가 문장으로 나온다. 완료 기준: 치수와 버튼 위치 문장을 확보.
2. 조건(예: "끼울 때 버튼이 눌리지 않아야 함")은 제품 나열 전에 **구조 문제로 번역**한다. 버튼 눌림 = 버튼을 덮는 일체형 커버의 안쪽 돌기와 조립 공차 문제이므로, 해결책은 "측면을 조이지 않는 자석 부착형" 또는 "버튼이 뚫린 오픈형"으로 좁혀진다. 완료 기준: 추천할 구조 1~2개를 문장으로 명시.
3. 후보 수집은 web_search로 시작한다. 완료 기준: 후보 3개 이상 또는 명확한 실패 확인.
4. web_search가 `bot-detection challenge`로 실패하면 재시도로 시간을 쓰지 말고 검색 페이지 직접 fetch로 즉시 전환한다. 네이버가 가장 유효하다: `https://search.naver.com/search.naver?query=<URL인코딩한 검색어>` — 결과 페이지에 상품명·최저가·배송비·평점·리뷰수·판매처가 텍스트로 들어 있다. Bing도 fetch되지만 일반 문서 위주라 쇼핑 데이터는 네이버가 낫다. 완료 기준: 상품명+가격+평점을 2개 이상 확보.
5. 판매처 개별 상품 페이지(`smartstore.naver.com/<스토어>/products/<id>`)는 fetch하지 않는다. 429 또는 "시스템오류" 페이지만 돌아온다. 상세 설명은 검색 결과 요약과 제조사 공식 페이지로 대체한다. 완료 기준: 인용한 모든 수치에 실제로 읽은 출처가 있음.
6. 다나와(`search.danawa.com`)는 제조사·분류 필터만 반환하고 상품 목록은 JS 렌더링이라 상품 수집에 쓰지 않는다. 참고용 브랜드 확인 정도로만.
7. 답변은 세 부분으로 나눈다: ① 조건에 맞는 모델명+가격+평점+조회 날짜(네이버 최저가 기준임을 명시) ② 그 구조가 조건을 만족하는 이유 ③ 구매 전 상품 사진에서 직접 확인할 체크 항목. 가격은 변동된다는 문장을 반드시 넣는다. 완료 기준: 추측을 사실처럼 쓴 문장이 없음.
8. "여러 세대 겸용" 표기 제품보다 대상 세대 전용 표기를 우선 추천하고, 제품 사진에서 컷아웃(버튼·카메라)을 확인하라고 안내한다. 완료 기준: 세대 지정과 확인 안내가 답변에 포함.

## 상품 사진을 보여줘야 할 때

판매처 상품 페이지는 429/418/403으로 막히므로(스마트스토어 429, `search.shopping.naver.com` 418, 쿠팡 403, G마켓 403) 네이버 **이미지** 검색 HTML을 쓴다: `curl`로 `https://search.naver.com/search.naver?where=image&sm=tab_jum&query=<URL인코딩 검색어>` + UA와 `Accept-Language: ko-KR,ko;q=0.9`. 완료 기준: 응답 HTML 확보.

응답에서 `"title":"..."`와 `"viewerThumb":"..."`를 짝으로 파싱한다: 패턴 `"title":"((?:(?!","title").)*?)".*?"viewerThumb":"((?:(?!","title").)*?)"`. `\u0026`, `\/` 이스케이프를 푼 뒤 title에 브랜드·스토어명이 들어 있으므로 대상 세대(예: "에어 11")와 브랜드가 함께 보이는 항목만 고른다. 완료 기준: title로 제품을 식별한 이미지 URL 확보.

`viewerThumb`는 `https://search.pstatic.net/common/?src=...&type=sc960_832` 형태라 그대로 내려받아 첨부할 수 있다. Bing 이미지 결과의 `purl`/`murl`/`t` JSON도 같은 목적으로 쓸 수 있지만 네이버보다 커버리지가 낮다. 완료 기준: 후보 이미지 2개 이상 로컬 저장.

이미지는 반드시 워크스페이스 안에 저장한다(예: `<workspace>/media/<주제>/`). TEMP 경로는 `view_image`와 `MEDIA:` 첨부에서 "not under an allowed directory"로 거부된다. `view_image`로 확인한 뒤 첨부한다. 완료 기준: 첨부 이미지의 색상·형태가 해당 제품임을 눈으로 확인.

중계 프록시(r.jina.ai, codetabs, allorigins)는 403/408/522로 실패하므로 시도하지 않는다.
