# 손글씨 스캔 판독·정리

"첨부 손글씨는 …임", "판독해줘", "정리해서 앞으로 쓸 수 있게 해줘" 요청에 쓴다.

## 1. 원본 해상도로 이미지 추출

- PDF는 PyMuPDF를 쓴다(Python 3.11, fitz 1.28). 페이지를 400~900dpi로 렌더하지 말 것 — 내장 스캔 이미지(예: 2480x3508)가 최대 해상도이고, 더 높은 dpi 렌더는 보간만 늘어 더 흐려진다.
- 내장 이미지를 그대로 뽑는다: `doc[0].get_images(full=True)`로 xref를 얻고 `fitz.Pixmap(doc, xref).save(path)`.
- 스크립트는 `workspace/tmp/*.py`에 쓰고 `python <경로>`로 실행한다. 콘솔 한글 출력은 깨지므로 결과는 파일로 쓰고 `read`로 본다.

## 2. 줄 단위 이진화 크롭

- 회색조 변환 후 획이 있는 행을 찾아 줄 묶음을 만든다: `a = np.array(im)`, `(a < 140).sum(axis=1) > 8`, 12px 이내 연속 행을 한 줄로 묶는다.
- 이진화는 하한 정규화 후 고정 임계가 잘 먹는다: `lo = np.percentile(a, 1)`, `hi = np.percentile(a, 60)`, `n = clip((a-lo)/(hi-lo)*255)`, `bw = n < 130`.
- 색 채널 분리(`(R+G)/2-B`)로 파란 잉크를 뽑는 방식은 흰 글씨가 되어 판독 불가였다 — 쓰지 않는다.

## 3. 판독

- `view_image`는 줄마다 따로 호출한다. 여러 줄을 한 번에 넣으면 축소돼 판독률이 떨어진다.
- 라벨과 표제를 먼저 확정하고, 값(숫자·영문 코드)은 그 부분만 잘라 2~3배 LANCZOS 확대해 다시 본다.
- 고유명사·숫자·영문은 모양 그대로 옮긴다.

## 4. 결과 처리

- 완료 기준: 판독한 각 줄을 그대로 제시하고, 확신 없는 글자에는 `?`를 붙인 "확인 필요" 목록을 만들어 한 번에 확인 요청한다. 추측으로 값을 확정하지 않는다.
- "앞으로 쓸 수 있게 정리해줘"면 워크스페이스에 `이름.md`(항목·절차·확인 필요)와 원본 이미지 사본 `이름-원본.png`을 저장하고 두 경로를 보고한다.
- 확인받은 값은 저장한 md에서 고친다.
