# CWI 시험·교육 일정 조회 (KWIC/KETC)

## 언제 쓰나
- 지우(유이사님)가 AWS CWI(용접검사원) 시험·교육 일정, 장소, 시간표를 물어볼 때 (예: "CWI Part B 실습교육이 언제 있어?")
- 특정 시험 회차의 교육 일정을 확정해야 할 때, 또는 새해 교육 공지(매년 2월경 등재)를 찾을 때

## 사전 배경
- 한국 CWI 교육·시험 대행 기관 2곳:
  - **KWIC(한국용접공업협동조합)** — 서울 금천구 가산(더루벤스밸리 703호) 등 회차별 정규시험 + 교육 병행. 지우는 KWIC 응시(10/31 = 2026년 6회차).
  - **KETC(https://www.asmeketc.com/cwi)** — AWS 공식 에이전트, Part B 시험은 수원. 찾는 시험일이 KWIC 일정에 없으면 KETC 확인.
- 교육 방식: **온라인(Part A·C, Zoom 월수금 20:30~23:30, 4주) + 오프라인(Part B 실습)**. Part B 실습은 통상 시험 1~2주 전 토~일 2일, 장소는 회차별(부산/서울 등)로 다름.
- Part B 실기 후 30일 이내 Prometric CBT로 Part A·C 응시(조합 공지 기준).
- 상세 문의: weldingkorea@kwic.or.kr

## 절차

1. **회차 확정**: 시험 날짜를 KWIC 정규시험 일정(`http://www.kwic.or.kr/sub_03_02.html`)과 대조해 "N회차 시험 = M월 D일(토)"를 특정한다. 같은 페이지에 응시료·접수서류·시험장소도 있음.
   - 완료 기준: 시험일 ↔ 회차 번호 매칭 완료.

2. **교육 공지 찾기**: 공지 목록 `http://kwic.or.kr/sub_05_05.html`에서 "N년 CWI 교육 실시안내" 게시물을 연다 (2026년분 = id 9022, 2025-02 등재; 새해엔 새 id). 본문에서 교육 방식(온라인 A·C / 오프라인 B) 확인.
   - 완료 기준: 게시물 본문 확보.

3. **첨부 xlsx 링크 확보**: 회차별 세부 일정은 xlsx 첨부에만 있다. readability/web_fetch는 첨부 링크를 지우므로 **원본 HTML을 curl로 받아** 링크를 뽑는다:
   ```
   curl.exe -s "<view URL>" -o page.html
   Select-String -Path page.html -Pattern 'dnload.inc.php\?fn=' -AllMatches
   ```
   링크 형태: `http://kwic.or.kr/QuickBoard/dnload.inc.php?fn=9022_f4_459.xlsx&fn2=<EUC-KR 파일명>`.
   - 판별: `fn2` 파일명은 EUC-KR이라 '?'로 깨져 보이지만 **시험 날짜 조각(예: `10?? 31??`)이 든 파일**을 고르면 된다. `fn=9022_fN_...`의 N도 시험 회차 순서와 일치하는 경향.
   - 완료 기준: 대상 회차 xlsx 1개 다운로드.

4. **xlsx 시간표 읽기** (Excel 없이): 확장자를 `.zip`으로 바꿔 `Expand-Archive` → `xl/sharedStrings.xml` + `xl/worksheets/sheet1.xml`을 파싱해 행 단위로 재조립. 범용 파서: `scripts/read-xlsx-rows.ps1` (인자: xlsx 경로). 시간표 머릿말에 "CWI 제 N차교육 시간표 (YYYY년 M월 D일 시험대비)"가 있어 회차·대상 시험일 재확인 가능.
   - 완료 기준: "09:00~09:50 | BOS(Clause 1.0 & 2.0)..." 형태의 행 텍스트 출력.

5. **날짜 검증 (오타 함정)**: 시간표 머릿말의 연도가 **전년도로 남아 있는 오타**가 흔하다(예: 2026 시간표인데 "2025년" 표기). 적힌 모든 날짜의 요일(월/수/금, 토/일)이 한 연도에만 정확히 맞으면 그 연도 기준으로 확정한다. (실제 사례: 2026-09-16=수, 10-24=토 모두 2026에만 일치 → 2026 확정)
   - 완료 기준: 시험일·교육일의 요일-연도 일치 확인.

6. **결과 정리**: ① 오프라인 Part B 실습 날짜·장소 ② 온라인 Part A·C 기간을 보고하고, 임시 파일(page.html, xlsx, zip, 해제 폴더)은 정리한다. 세부 장소·Zoom 링크 등은 담당 교수/조합이 응시자에게 별도 공지하므로 "조합 확인" 안내를 덧붙인다.

## 주의
- 웹페이지가 EUC-KR: 제목·파일명은 깨져 보여도 본문 날짜·요일은 정상이므로 내용으로 판별.
- 교육기관에 따라 "시험 또는 교육만 단독 등록 불가" 정책이 있음(등록·비용은 기관 직접 문의).
